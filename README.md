# FinScope

**面向个人与小微商户的财务管理与分析平台**

FinScope 将日常记账、账户管理、经营台账、账单导入、票据识别和财务分析整合到统一的工作空间中，帮助用户了解资金去向、账户余额及经营状况。

项目采用前后端分离架构，提供适配桌面和移动端的深色界面。财务计算由后端确定性程序完成，统计结果结合图表、指标与分析依据呈现，兼顾可读性、金额精度和数据可追溯性。

## 核心功能

### 工作空间与成员协作

- 支持个人与商户两类工作空间，分别组织不同用途的财务数据。
- 提供空间切换、成员管理和所有者、管理员、成员、只读成员四种角色。
- 每个工作空间采用独立的基础币种，支持 CNY、HKD、USD 和 EUR。
- 服务端校验成员权限及关联数据归属，约束不同空间的数据访问。

### 账本与账户管理

- 管理账户、收支分类、收入、支出、退款及内部转账。
- 支持期初余额、带原因的余额调整，以及交易编辑和撤销。
- 展示账户余额、收支流水、分类汇总及操作记录。
- 区分收支、退款、转账和余额调整，保持统计口径清晰。

### 商户经营分析

- 管理营业收入、经营成本和经营费用。
- 登记应收应付，支持分次结算及结算撤销。
- 查看简化利润、现金流、未结余额与逾期指标。
- 区分业务确认和实际收付款，避免结算重复计入利润。

### 可视化财务总览

- 以指标卡片展示收入、支出、结余及账户余额。
- 提供每日趋势、分类分布和经营指标图表。
- 支持按日期范围查看统计，连接总览、账本和经营台账。
- 金额文本保留十进制精度，图表与统计采用统一的数据口径。

### 账单导入与票据识别

- 支持 CSV、XLSX 账单导入，提供字段映射、数据预览和重复记录提示。
- 导入数据经过校验与人工确认后，再写入正式账本。
- 提供票据上传、Windows 本地 OCR、规则字段提取和手工修订。
- 票据候选信息须经人工核对后确认入账。
- 可选云端票据提取默认关闭，启用后按次授权处理文字内容。

### 财务分析

- 围绕收支总结、支出趋势、分类表现及商户利润等固定主题进行分析。
- 复用经过权限校验的统计工具，展示指标、计算依据和规则建议。
- 保存分析快照与历史记录，方便回看当时的统计结果。
- 当前使用本地规则与确定性计算，外部财务 AI 保留扩展接口。

### 多端体验

- 桌面使用统一侧栏，移动端使用底部导航与更多功能菜单。
- 结合空间类型和成员角色展示入口，提供快捷记账操作。
- 支持在线 PWA、安装提示、网络状态提示和经用户确认的应用更新。
- 提供轻量过渡、交互反馈与减少动态效果设置。

| 部署方案 | Docker Compose、Nginx、HTTPS 反向代理 |

## 设计特点

**金额精度。** 金额以十进制字符串传输，后端使用 Decimal 计算；PostgreSQL 使用 NUMERIC，本地 SQLite 使用整数分存储。

**可追溯账务。** 交易更正通过反向资金记录和新记录表达，并保留审计信息，便于追查资金变动。

**一致的写入流程。** 账务记录、资金变动、审计和幂等结果在同一数据库事务中提交，结合版本检查处理重复提交与并发修改。

**确定性分析。** 金额与财务指标由程序计算，分析层引用已有统计与证据；预留的 AI 扩展接口遵循相同的数据边界。

**模块化结构。** 认证、工作空间、账务、经营、报表、导入、票据和分析按业务模块组织，便于维护和逐步扩展。

## 适用场景

- 个人日常收支记录、账户整理和消费结构分析。
- 小微商户的收付款管理、应收应付跟踪和简化经营分析。
- 围绕财务业务开展全栈开发、数据建模与可视化实践。

FinScope 聚焦个人与小微商户的管理分析，采用简化业务口径，便于将账务记录、统计结果与实际资金变化联系起来。
