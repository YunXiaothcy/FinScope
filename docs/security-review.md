# 安全审查与验证报告

交付日期：2026-10-25。范围：本独立版本的后端、前端、迁移、部署文件、维护脚本和测试。审查不包含原项目的真实数据库、上传内容、密钥、日志或历史 Git 对象。

## 结论及适用范围

已修复本轮发现的问题，完成代码检查、依赖扫描、安全回归和隔离本机 HTTP 验证。本报告不构成“所有漏洞已消除”或“完整渗透测试通过”的证明。公网服务器、真实浏览器、Linux 容器和多实例环境尚未完成安全验收。

导航调整已同步到原开发项目和本版；下表中的后端加固只在本独立版本中交付。原开发项目仍使用自身代码、端口和数据库，不能直接引用本报告作为原运行服务的安全结论。

## 发现及修复

| 问题 | 修复 | 验证证据 |
| --- | --- | --- |
| 生产退出时删除的 Cookie 名称与创建时不一致 | 使用同一 Cookie 配置，准确删除 `__Host-` 会话 Cookie，保留 Secure/HttpOnly/Path 属性 | 安全 Cookie 注销与旧会话重放用例 |
| 认证、JSON 和分块上传缺少统一的解析前大小限制 | ASGI 层限制认证体 8 KiB、普通 API 128 KiB、导入 2 MiB、图片 5 MiB；限制读取时间、并发和头部大小，拒绝压缩及歧义长度 | 413/415/400/408 用例及真实 HTTP 检查 |
| 认证请求可通过切换账号消耗密码哈希资源 | 增加 IP 总预算、原子账号预算、改密预算和密码哈希并发上限，限制密码长度 | 并发限流、轮换账号和登录预算用例 |
| 不存在账号的登录路径跳过密码校验 | 使用一次性生成的虚拟密码哈希完成同类校验，统一登录错误信息 | 认证回归；不宣称消除全部时间侧信道 |
| 限流字典可持续增长 | 共用有界、加锁、按时间清理的窗口限流器 | 并发与键容量用例 |
| OCR 或外部整理期间权限被撤销，完成后仍可能写回 | 写回前重新读取会话、账号状态及成员角色，避免使用 ORM 缓存的旧权限 | 撤销/过期会话、停用账号、降为只读、删除成员用例 |
| 可选票据服务目标缺少明确公网出口限制 | 默认关闭；要求精确域名白名单、HTTPS/443；拒绝内部地址及混合 DNS 结果；连接固定为已检查的 IP，保留原 Host 和 TLS 主机名校验；禁止跳转和压缩响应 | MockTransport 与 DNS 模拟用例；没有调用真实外部服务 |
| 同一主机更改票据服务租户路径时，旧授权仍可能匹配 | 授权目标包含完整 API 基址和模型；目标变化要求重新授权 | 票据授权与配置回归 |
| 前端可配置外部 API 基址 | API 基址固定同源 `/api/v1`，拒绝绝对、协议相对及其他路径；禁止 fetch 跳转 | 前端配置校验用例 |
| 本地 Uvicorn 默认信任回环代理头，伪造转发 IP 会影响限流 | 本地启动明确禁用代理头；生产只信任明确代理网络，Nginx 覆盖转发头 | 首次隔离 HTTP 检查发现问题，修复后伪造转发 IP 的限流检查通过 |
| 运行程序依赖 PATH 搜索、HTTPS 验收依赖可被优化移除的 assert | OCR 使用系统 PowerShell 完整路径，服务通过当前解释器启动；验收脚本改为显式条件失败 | Ruff、脚本回归和本地 OCR |
| 网关连接、读取时间和通用 API 预算不完整 | 补充 Nginx 连接/请求速率、头部/请求体时间限制，设置 Uvicorn 并发和 keep-alive 上限 | Nginx 原生配置检查；尚未做持续压力测试 |

登录限制与会话防护参考 [OWASP 认证指南](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。出口策略参考 [OWASP SSRF 防护指南](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)；固定 IP 时保留 TLS 主机名使用 [HTTPCore 的 SNI 扩展](https://www.encode.io/httpcore/extensions/#sni_hostname)。这些资料支持设计取舍，测试证据来自本项目实际执行结果。

## 脱敏与交付

- 使用源码白名单整理，排除真实 `.env`、数据库、上传目录、证书私钥、日志、备份、Git 历史、依赖、缓存和运行目录。
- 交付文件扫描常见服务密钥格式、私钥标记、个人机器路径及已知个人标识；不在报告中展示任何真实凭据。
- 测试中的密码、邮箱、号码和票据为虚构样例。Compose 私有网络段是通用部署默认值，安全用例内网地址是攻击测试输入，均不是用户真实服务器地址。
- `SOURCE-MANIFEST.json` 记录每个交付文件的 SHA-256；ZIP 旁另有 SHA-256 文件。摘要用于校验完整性，不是数字签名，也不能证明来源。
- 模式扫描和人工复核不能保证识别所有未知格式的秘密；新增真实配置和数据后必须重新执行导出审查。
