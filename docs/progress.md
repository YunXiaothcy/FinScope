# FinScope 独立安全版进度

更新日期：2026-10-25。

## 当前阶段

沿用阶段 9 的部署准备范围，按用户要求审查及规范化源码、修复发现的安全问题，并生成独立脱敏版本。财务 AI 保持预留状态，未接入外部财务 API。

## 已完成

- 全站统一导航：桌面固定侧栏、手机底栏；商户专属入口按空间类型显示；导入和票据归入数据录入；账本内部保留账户、分类和转账。新版导航也已同步原开发项目。
- 增加 UTF-8/LF/缩进约定，Python 由 Ruff 格式化及检查，前端由 Prettier、Vue TypeScript 和 Vite 检查。
- 修复生产退出 Cookie、请求资源限制、认证预算、限流内存、任务完成后的权限复查、可选票据服务出口限制、授权目标和同源 API 配置问题。
- 动态检查发现本地代理头可影响 IP 限流，已在本地启动禁用代理头，并保留生产的受控代理链。
- 隔离动态探针可重复执行，自动创建虚构数据库并停止自身测试进程。
- 源码交付排除用户数据、密钥、Git 历史和所有运行依赖；提供安全报告、启动说明、文件哈希清单及 ZIP。
