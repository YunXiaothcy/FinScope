# 阶段 7：AI 财务分析师

## 使用与验收

1. 确保已安装依赖、执行 `alembic upgrade head`，按 README 启动前后端。在账本、商户经营页或总览侧栏点击「AI 财务分析师」。地址为 `/workspaces/{workspace_id}/analysis`。
2. 无 API Key 时点击「我这个月在哪些类别花钱最多？」→「生成本地分析」。检查分类金额和账本一致，退款冲减原类别；内部转账不产生收入。展开全部指标与工具调用查看周期、香港时区和公式。
3. 提问「最近三个月我的支出有什么变化？」：分别显示最近三个自然月，本月仅到今天。不能把尚未结束月份与完整月份的金额直接判断为同比或完整月增长。
4. 商户提问「为什么这个月营业收入增长但利润下降？」：显示本期、比较期及四项差额，给出 `利润变化 = 收入变化 - 成本变化 - 费用变化` 的证据编号。程序解释数值关系，具体经营原因仍需核对凭据；应收应付结算不再次计入利润。
5. 「哪个费用类别增长最快？」按增长率降序显示最多十类。商户只比较经营费用，不含采购成本；个人比较支出。上期大于零才算百分比，非正基数只展示差额，排在有增长率的类别后；负增长率代表下降。
6. 自定义起止日期优先于问题中的相对日期，最长 366 天、不得晚于今天。月初开始的部分月比较上月相同日期，完整自然月比较完整上月；其他范围比较紧邻的等长期间。月末天数不同会明确提示。三个月趋势须清空自定义日期。
7. 提问预算、预测、执行 SQL、操作账务、跨空间或未支持的问题：明确提示数据不足/范围不支持，不编造答案。暂不提供指定商户、账户、单个类别的筛选；检测到已知对象名称或明确筛选指令时要求改问。
8. 刷新页面从「我的最近分析」重新打开；只有创建者且仍是空间成员才能读取，viewer 也可分析但不会获得记账权限。清理记录后快照和结果消失，账本不受影响。
9. 首次生成分析请求结果未收到时，在原页面点击「使用原编号安全重试」。不将问题放入浏览器持久存储，刷新后可以从历史找回成功记录；重新生成分析只会增加分析记录，不会记账。

### 用虚构数据核对

建议创建独立测试空间，避免改动真实账本。个人账户期初 `1000.00`，本月工资 `2000.00`、餐饮支出 `100.00`，并对该支出退款 `20.00`：

- 分类餐饮净支出 `80.00`；期间净收入 `2000.00`、净支出 `80.00`、结余 `1920.00`。
- 无其他调整时净资金变动 `1920.00`、期末余额 `2920.00`。内部转账不会改变这些合计。
- 商户比较例：比较期收入 `100.00`、成本 `20.00`、费用 `10.00`，利润 `70.00`；本期收入 `120.00`、成本 `50.00`、费用 `20.00`，利润 `50.00`。差额应为收入 `+20.00`、成本 `+30.00`、费用 `+10.00`、利润 `-20.00`。

## 外部 AI 当前仅预留接口

按用户在阶段 8 前的明确要求，财务分析当前**不接入外部服务、不读取或使用财务分析 API 密钥**，页面已移除云端预览与发送按钮。本地规则解析、精确统计、证据、建议、历史及清理仍可用。

预留 `POST /api/v1/workspaces/{workspace_id}/analysis/{id}/explain`。接口保留请求结构、登录、空间成员、记录创建者及 CSRF 检查，有权限的有效请求返回 `501`（尚未接入）。即使环境中存在历史 `FINSCOPE_AI_*` 配置，也不会启用调用。恢复外部集成必须另行开发并获得用户明确授权，单纯填入密钥不起作用。

AIProvider Protocol 与适配器源码仅供未来实现参考，当前 REST 链路不构造兼容 Provider，不调用其配置函数。兼容适配器的测试使用虚构配置与 MockTransport，不能代表真实服务验收。票据识别属于独立的 ReceiptExtractor 模块，本次未改变其按次授权机制，也没有运行真实票据云端调用。

## 本地数据流与边界

```text
已登录问题 + 已授权空间
  → 本地有限规则解析意图与周期
  → 应用选择固定只读统计工具（复用 business_report）
  → Decimal 指标 + 日期/公式 + 工具调用与不足提示
  → 不可变快照 + 固定证据引用模板与建议
```

不支持任意聊天或自由 SQL。模型没有数据库连接、空间选择参数或账务写入入口。金额和增长率由确定性代码计算，格式为精确十进制字符串；上期非正时不给增长率。

API 统一前缀 `/api/v1/workspaces/{workspace_id}/analysis`：

| 方法/后缀 | 用途 |
| --- | --- |
| GET `/capabilities` | 固定返回 ai_enabled=false、integration_status=reserved |
| POST 空后缀 | 本地提问；CSRF、Idempotency-Key，支持成对日期 |
| GET 空后缀 | 本人在本空间最近二十条未清理分析 |
| GET `/{id}` | 本人记录与统计快照 |
| POST `/{id}/explain` | 仅预留，权限通过后返回 501，不发生外部调用 |
| DELETE `/{id}` | CSRF，清理快照/结果，不影响账务 |

不同内容复用同一提问编号返回 409；同编号重试取已有快照。所有成员包括 viewer 可以分析，但只能读取自己的分析记录并继续接受成员校验。统计快照在三十天后按本人访问触发清理，也能主动清理；摘要、去重和必要审计保留，没有定时删除。

单进程总并发最多两次，单用户每分钟五次新分析，幂等重放不消耗次数。没有预算配置、预测、指定对象筛选、自由聊天或跨空间分析；没有记录不证明没有实际业务。报表仍扫描有效历史，海量流水需后续优化。
