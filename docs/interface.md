# 界面与简约动效

2026-10-24，按用户要求在现有阶段追加前端精修。

整体保留深色与薄荷绿，将强调色集中在主要操作和有效状态；面板使用细边框与轻阴影，次级操作采用描边按钮。财务数字直接展示，不做逐帧跳动或模拟分析进度。

## 文件与规则

| 文件 | 职责 |
| --- | --- |
| `frontend/src/style.css` | 颜色、面板、控件、响应式、分析页问题卡片与空状态 |
| `frontend/src/motion.css` | 页面/卡片/弹窗过渡，悬停、按压及减少动态效果设置 |
| `frontend/src/components/AppIcon.vue` | 本地 SVG 线性图标，无外部素材请求 |
| `frontend/src/App.vue` | RouterView 的页面淡入淡出，继续按 path 保持页面实例边界 |
| `frontend/src/views/AnalysisView.vue` | 示例选中反馈、加载指示、本地分析标识及历史空状态 |
| `frontend/src/components/WorkspaceNavigation.vue` | 桌面侧栏、手机底栏及更多菜单共用导航定义 |

页面根节点仅改变透明度，不能随意给它加 transform/filter：这些属性可能改变内部 fixed 弹窗的定位参照。指标卡及弹窗自身可以短暂移动；不让长期展示的金额不断运动。长列表不逐行错峰，避免等待阅读。

动效通常在 160–320ms 内完成。仅指标卡最初四项最多错开 105ms；只在加载按钮中保留旋转指示，系统开启减少动态效果时也停止。没有常驻背景动画或额外动画库。

## 手动体验

1. 打开 5174 开发页，登录并切换工作空间、账本、总览和分析。页面应短暂淡入，查询参数切换不应重新创建账本表单。
2. 在分析页选择不同问题卡片，选中项显示薄荷绿边框与勾号；生成本地分析时按钮显示等待状态，完成后金额直接显示。已有记录仍能刷新与清理。
3. 查看账本、总览和经营的指标卡；悬停按钮与工作空间卡片应只有轻微反馈，普通流水不会跟随指针移动。
4. 打开取消/清理等确认弹窗，滚动页面后检查遮罩覆盖视口。关闭后原页面表单保持原状态。
5. 在 320/390/768px 宽度检查顶部链接换行、问题卡片列数、手机底部导航和更多菜单；按钮焦点轮廓清楚，触控目标保留至少 44px。
6. 在系统辅助功能中开启“减少动态效果”，检查页面、卡片、菜单和加载指示不再运动；功能与反馈文字继续可用。

已通过 17 项前端回归、格式、类型、生产构建及开发模块 HTTP 检查。以上真实浏览器/手机体验尚未实测；没有声称完成逐页视觉、键盘或屏幕阅读器审计。


## 统一导航（2026-10-24）

- 所有工作空间页面共用桌面侧栏：财务总览、账本、商户经营（仅商户）、财务分析；数据录入分组包含账单导入、票据识别。
- 侧栏显示当前空间、币种及角色，底部提供记一笔和切换空间与设置。账户、分类、转账、操作记录留在账本内。
- 手机主入口为总览、账本、记一笔、分析、更多；只读角色不显示记账按钮。更多菜单显示其余入口及当前空间，进入导入/票据/经营页时更多保持选中提示。
- 记一笔属于动作，账本仍是选中的页面，避免同一路径产生两个“当前页”。路由切换、Esc、点击外部、切换桌面尺寸关闭更多菜单。
- 选中判断使用完整路径边界，切换空间时清空旧信息并忽略过期响应。主内容与导航图标沿用现有动效及减少动态效果设置。
- 本轮实际通过 19 项前端测试、类型检查与生产构建。尚未做浏览器逐页视觉和真实手机触控验收。
